## 正文简介（B站 / 抖音描述区）

```
在 ESP32-S3 上跑一个真正的 Minecraft Java 版服务器。

一块 30 块钱的芯片，8MB 内存，撑起了地形生成、方块破坏、物品合成、
生物 AI，还能几个人同时在线。

这版做了几件事：

▸ 内存优化
  内部 SRAM 从只剩 89KB（历史最低 547 字节，几乎耗尽）
  提到 219KB —— 把 120KB 的方块数据挪进了 PSRAM

▸ 延迟优化
  局域网 ping 从 185ms 平均 / 393ms 峰值
  降到 16ms 平均 / 5ms 抖动
  根因不在网络，在主循环里每个包都多了一次 vTaskDelay

▸ 主循环修复
  一个 continue 写错了位置，让 94% 的循环轮次什么都没干。
  表现出来就是：断电后 30 秒才提示断线、摔不死、挖方块不掉落

▸ TCP 遥控台
  不用接串口，局域网里直接管理
  list / give / tp / kick / say / setblock / fill …共 20 条命令

▸ 网页配网
  不用改代码重新编译，连热点打开网页填 WiFi 就行
  连不上会自动重开热点

⚠️ 说清楚它做不到什么：
没有下界和末地，所以打不了龙，通不了关
没有附魔、酿造、红石，TNT 也点不着
方块偶尔会渲染成透明

这是个技术演示项目，不是能日常用的服务器。
作者本人也说 "this won't cut it"。

项目基于 p2r3/bareiron 和 jeyyprtf/esp32-mcserver 修改，
用 AI 工具辅助开发，开源，GPL-3.0。

代码和固件：github.com/huang5200075/esp32-s3-minecraft-server

#ESP32 #我的世界 #Minecraft #单片机 #嵌入式 #开源 #DIY
```
